# v4

im bored as hell

A full-screen generative artwork built with vanilla JavaScript and p5.js.

- Click, tap, press Space, or press Enter to cycle through seeded plume, creature, and ray forms.
- Use the reduced-motion toggle to slow each form's procedural time step.
- Resize the window freely; the canvas and point budget adapt to the viewport.

## Development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.
